LIÇÃO 39 — Conditionals: Zero & First Conditional

Nível B1
🎯 Objetivo da Lição

• Usar o Zero Conditional para fatos e verdades gerais.

• Usar o First Conditional para possibilidades reais no futuro.

• Usar corretamente if, unless, when, as soon as.

🔥 Warm-Up: Se isso, então aquilo

Condicionais conectam uma condição a um resultado. Existem vários tipos, mas hoje vamos ver os dois mais usados no dia a dia:

If you heat water, it boils. (fato sempre verdadeiro — Zero Conditional)

If it rains, I'll stay home. (possibilidade real no futuro — First Conditional)

💡 Dica: Zero Conditional = verdade sempre. First Conditional = possibilidade real, ainda vai acontecer ou não.

🗣️ Diálogo: Weekend Plans (Maybe)

Nina: If it's sunny tomorrow, we'll go to the beach.

Caio: And if it rains?

Nina: If it rains, we'll watch movies instead.

Caio: Good plan! You know, if you don't check the weather forecast, you never know what to expect.

Nina: True! If water freezes, it becomes ice — that's a fact. But weather predictions aren't always facts!

Caio: Ha! Well, unless something changes, I'll pick you up at 9 a.m.

Nina: Perfect. As soon as I wake up, I'll check the forecast and text you.

Caio: Sounds good. See you tomorrow!

🔁 Repita com atenção: Identifique quais frases são Zero Conditional (fato) e quais são First Conditional (possibilidade futura).

📘 Gramática em Ação: Conditionals
1. Zero Conditional — fatos e verdades gerais

Estrutura: If + Simple Present, Simple Present

If you heat water, it boils. | If people don't eat, they get hungry.

Usado para fatos científicos, verdades universais e rotinas/hábitos.

2. First Conditional — possibilidades reais no futuro

Estrutura: If + Simple Present, will + verb

If it rains, I'll stay home. | If you study hard, you'll pass the exam.

Usado para situações reais e possíveis no futuro — algo que realmente pode acontecer.

3. Unless = if...not

Unless you hurry, you'll miss the bus. = If you don't hurry, you'll miss the bus.

4. When e As soon as (certeza, não possibilidade)

Diferente de "if", "when" e "as soon as" indicam que o evento vai acontecer com certeza — só não sabemos exatamente quando.

When I get home, I'll call you. (tenho certeza que vou chegar em casa)

As soon as she arrives, we'll start the meeting.

Dica prática: NUNCA use "will" na oração com "if" (a parte da condição): ❌ "If it will rain" → ✅ "If it rains".
📝 Exercícios
A. Complete com Zero ou First Conditional.
If you (heat) ice, it melts.
If it (rain) tomorrow, we'll cancel the trip.
If she (study), she'll pass the test.
Plants (die) if they don't get water.
B. Escolha a opção correta.
If you don't hurry, you ___ miss the train.
Water boils ___ it reaches 100°C. (fato)
I won't go ___ you come with me. (a menos que)
Qual está correta?
C. Traduza usando o condicional apropriado.
1. Se você aquece água, ela ferve. →
2. Se chover, eu vou ficar em casa. →
3. Assim que eu chegar, eu ligo para você. →
D. Verdadeiro ou Falso?
No Zero Conditional, usamos "will" na oração principal.
"Unless" significa a mesma coisa que "if not".
Podemos usar "will" logo após "if" na oração condicional.
🎭 Prática Oral / Role-Play

A: What will you do if you win the lottery?

B: If I win the lottery, I'll travel around the world!

A: And if you don't win?

B: Unless something changes, I'll just keep working. Ha!

🌍 Curiosidade Cultural: Conditionals in Everyday Life

Condicionais aparecem o tempo todo em contratos, avisos e instruções: "If you press this button, the machine stops." ou "Unless otherwise stated, all prices include tax." Dominar essas estruturas é essencial para ler documentos e instruções em inglês corretamente.
