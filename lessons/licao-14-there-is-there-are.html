1

🎯 Objetivos

There is / There are

1️⃣

There is

Singular: There is a book.

🔢

There are

Plural: There are two books.

❓

Perguntas

Is there…? Are there…?

2

📘 Estrutura

There is a park near my house.
There are three chairs in the room.
Is there a garden? — Yes, there is. / No, there isn't.
Are there any students? — Yes, there are. / No, there aren't.
💡

Use some em afirmativas no plural: There are some books.

Use any em perguntas/negativas: Are there any books? There aren't any.
